# Executive Fiber Website

The official website for **Executive Fiber**, an internet service provider serving customers across the country. A multi-page static site built with plain HTML, CSS and JavaScript.

## Features

- Multi-page layout (home, packages, about, contact and more)
- Pricing toggle to switch between plan options
- Animated UI elements and smooth transitions
- Contact and sign-up forms powered by Netlify Forms
- Team section with portraits
- Responsive design for phones, tablets and desktops

> Edit this list to match the pages and features you have actually built.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- [Netlify](https://www.netlify.com/) for hosting and form handling

## Getting Started

### Run locally

No build step is needed.

```bash
git clone https://github.com/Iannmc/Executive-fiber.git
cd Executive-fiber
```

Then open `index.html` in your browser, or use the **Live Server** extension in VS Code (right-click `index.html` → **Open with Live Server**).

> Netlify Forms only work once the site is deployed on Netlify. Submitting a form locally will not send anything.

## Deployment

The site is deployed on Netlify.

1. Push your changes to the `main` branch on GitHub.
2. Netlify detects the update and redeploys automatically.
3. Form submissions appear in the Netlify dashboard under **Forms**.

To set it up the first time: in Netlify choose **Add new site → Import an existing project**, connect your GitHub repo, leave the build command empty, and set the publish directory to `/` (the project root).
